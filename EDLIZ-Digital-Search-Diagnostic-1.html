Operating workflow

Controls proposed for a future validated information-retrieval system.

  1. Source control: confirm the approved EDLIZ edition and document version.
  2. Extraction: process the PDF while preserving page and chapter boundaries.
  3. Indexing: attach edition, chapter, page and passage identifiers to each indexed passage.
  4. Query capture: record the search terms, filters, date and query identifier.
  5. Retrieval: return only passages found in the approved source.
  6. Evidence validation: verify that each citation supports the response and opens at the correct page.
  7. Response: provide concise source-linked information and state when evidence is missing.
  8. Human review: document acceptance, correction or rejection by an authorised reviewer.
  9. Continuous improvement: review search failures and update the index under version control.
Current prototype boundary: This version includes a searchable text index extracted from the supplied 673-page EDLIZ 2025 PDF, page references, a local PDF viewer and a local audit demonstration. It does not use a live AI model or replace professional clinical judgement.
